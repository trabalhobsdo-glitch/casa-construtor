# Casa do Construtor - Landing Page

Site estático (HTML/CSS/JS). Suba no GitHub e importe na Vercel (sem build).

- Edite `script.js` (bloco CONFIG) para definir o link de checkout.
- Logo dos Correios: coloque o arquivo em `assets/correios.png` (aparece sozinho no frete grátis).


## Atualização visual
- Faixa superior animada com informações de pagamento, envio, frete e compra protegida.
- Descrição vertical completa do produto em largura total.
- Ajustes visuais e responsivos para desktop e celular.
- Para configurar o checkout, edite `checkoutUrl` no início de `script.js`.
