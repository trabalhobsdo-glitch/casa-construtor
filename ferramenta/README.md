# Casa do Construtor — Kit 4 em 1 Ferramentas 48V

Landing page estática em HTML, CSS e JavaScript, pronta para GitHub + Vercel.

## Produto
- Kit 4 em 1: martelete rompedor, esmerilhadeira, parafusadeira/furadeira e chave de impacto.
- Preço promocional configurado: R$ 97,90 (de R$ 639,99).
- Galeria substituída pelas 10 imagens do novo produto.
- Descrição vertical e fotos adicionais incluídas.

## Publicação
1. Envie os arquivos desta pasta para o repositório GitHub.
2. Importe o repositório na Vercel ou aguarde o deploy automático.
3. Configure `checkoutUrl` no bloco `CONFIG` de `script.js` para conectar o checkout.

O prazo de entrega e as opções de pagamento devem ser confirmados/configurados no checkout.
